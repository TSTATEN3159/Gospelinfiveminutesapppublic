## 1. Stop trusting AI for the “correct answer”

Right now your AI generator is probably returning something like:

```json
{
  "question": "Which book contains the verse 'The Lord is my shepherd'?",
  "options": ["Proverbs", "Psalms", "Isaiah", "Ecclesiastes"],
  "correctIndex": 0,
  "reference": "Psalm 23:1"
}
```

The UI is doing exactly what you told it: it marks `options[correctIndex]` (Proverbs) as correct. The **bug is in the data**.

To **guarantee correctness**, we should **anchor the answers in a curated dataset**, *not* in AI’s memory. AI can help you phrase questions later, but **the correct answer and index must come from your own data.**

### 1.2 Use curated questions in the trivia route (instead of free AI)

In `server/routes.ts`, change your `/api/bible-trivia` route to draw from this dataset:

```ts
// server/routes.ts
import { z } from "zod";
import {
  STATIC_TRIVIA_QUESTIONS,
  TriviaLevel,
  StaticTriviaQuestion,
} from "./staticTriviaQuestions";

const bibleTriviaSchema = z.object({
  level: z.enum(["beginner", "intermediate", "advanced"]).default("beginner"),
  count: z.number().min(1).max(10).default(10),
});

function sampleQuestions(level: TriviaLevel, count: number): StaticTriviaQuestion[] {
  const pool = STATIC_TRIVIA_QUESTIONS.filter((q) => q.level === level);
  if (pool.length <= count) return pool;

  const indices = Array.from({ length: pool.length }, (_, i) => i);
  for (let i = indices.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [indices[i], indices[j]] = [indices[j], indices[i]];
  }
  return indices.slice(0, count).map((idx) => pool[idx]);
}

app.post("/api/bible-trivia", async (req, res) => {
  try {
    const { level, count } = bibleTriviaSchema.parse(req.body);
    const typedLevel = level as TriviaLevel;

    const questions = sampleQuestions(typedLevel, count);

    res.json({
      questions: questions.map((q) => ({
        id: q.id,
        question: q.question,
        options: q.choices,
        correctIndex: q.correctIndex,
        reference: q.reference,
        explanation: q.explanation,
        category: q.category,
      })),
    });
  } catch (err: any) {
    console.error("Bible trivia error:", err);
    res.status(500).json({ error: "Failed to get trivia questions." });
  }
});
```

Now the **“Proverbs vs Psalms” type errors disappear**, because **YOU** set the `correctIndex` and reference, not the model.

> Later, if you still want “thousands of questions,” we can design a safe offline pipeline where AI proposes candidates that you verify before adding them to `STATIC_TRIVIA_QUESTIONS`.

## 2. Show immediate feedback + explanation + verse reference

Now that the data is correct, let’s make the user experience match what you described:

> “The user should be able to see immediately if their answer was right or wrong, with a short explanation of the right answer that shows what Book and Verse in the Bible contains the right answer.”

### 2.1 Extend the frontend question type

In `client/src/services/triviaService.ts`, make sure `TriviaQuestion` includes `reference` and `explanation`:

```ts
export interface TriviaQuestion {
  id: string;
  text: string;
  choices: string[];
  correctIndex: number;
  reference?: string;
  explanation?: string;
}
```

And in the normalizer, read them from the API:

```ts
function normalizeQuestion(raw: RawTriviaQuestion, index: number): TriviaQuestion {
  const text = raw.question ?? raw.text ?? raw.prompt ?? "Question missing from API response";
  const choices = raw.choices ?? raw.options ?? [];
  const correctIndex =
    raw.correctIndex ?? raw.answerIndex ?? raw.correctOptionIndex ?? 0;

  return {
    id: raw.id ?? String(index),
    text,
    choices,
    correctIndex,
    reference: raw.reference,
    explanation: raw.explanation,
  };
}
```

Make sure `RawTriviaQuestion` includes these fields:

```ts
export interface RawTriviaQuestion {
  // ...
  reference?: string;
  explanation?: string;
}
```
