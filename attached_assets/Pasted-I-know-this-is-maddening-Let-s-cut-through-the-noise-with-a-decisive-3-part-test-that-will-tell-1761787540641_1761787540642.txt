### Why this is the fastest path

* **Step A** removes the proxy entirely. If that works, we’re done.
* If it still fails, **Step B** grabs the exact runtime error from the real device (no more guessing).
* **Step C** gives a minimal wrapper (no autoplay, no JS API, no framing headers) to avoid header conflicts if you must keep a wrapper.

Once you run Step A, you’ll know in one build whether the proxy is the culprit.
