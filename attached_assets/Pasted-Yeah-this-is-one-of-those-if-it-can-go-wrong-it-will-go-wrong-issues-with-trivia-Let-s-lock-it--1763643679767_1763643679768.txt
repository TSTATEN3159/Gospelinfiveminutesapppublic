Yeah, this is one of those “if it can go wrong, it will go wrong” issues with trivia. Let’s lock it down so the game cannot mark the wrong answer ever again.

The short version:
👉 Stop letting AI or any dynamic logic decide what’s correct at answer time.
👉 Always grade against a fixed, pre-validated answer key.

Below is a pattern you can drop into your app that makes wrong answers essentially impossible unless the data itself is wrong—and even that we can guard against.

1. Use a fixed data structure with an explicit correct answer

Create a triviaQuestions.ts (or similar) with a clear answer key:

// server/src/trivia/triviaQuestions.ts

export interface TriviaQuestion {
  id: string;
  question: string;
  options: string[];             // e.g. ["Genesis", "Psalms", "Proverbs", "Isaiah"]
  correctOptionIndex: number;    // e.g. 1  (0-based index)
  reference: string;             // e.g. "Psalm 23:1"
  explanation: string;           // short explanation shown after answering
}

export const TRIVIA_QUESTIONS: TriviaQuestion[] = [
  {
    id: "psalm-shepherd",
    question: "In which book do we find the verse, 'The Lord is my shepherd; I shall not want'?",
    options: ["Genesis", "Psalms", "Proverbs", "Isaiah"],
    correctOptionIndex: 1,
    reference: "Psalm 23:1",
    explanation: "This famous shepherd verse is in the book of Psalms, not Proverbs.",
  },
  // ... more questions here
];


Key points:

correctOptionIndex is the only source of truth.

We never ask the model (or any other logic) to “decide” what’s right when the user answers.

2. Grade answers only by the stored answer key

Where you handle the user’s answer, keep it brutally simple:

// server/src/trivia/checkAnswer.ts
import { TRIVIA_QUESTIONS } from "./triviaQuestions";

export interface CheckAnswerResult {
  isCorrect: boolean;
  correctOptionIndex: number;
  reference: string;
  explanation: string;
}

export function checkAnswer(
  questionId: string,
  selectedOptionIndex: number
): CheckAnswerResult | null {
  const question = TRIVIA_QUESTIONS.find(q => q.id === questionId);
  if (!question) {
    // If this ever happens, something is wrong with the client/server sync
    console.error(`Question not found: ${questionId}`);
    return null;
  }

  const isCorrect = selectedOptionIndex === question.correctOptionIndex;

  return {
    isCorrect,
    correctOptionIndex: question.correctOptionIndex,
    reference: question.reference,
    explanation: question.explanation,
  };
}


Then in your API route:

// server/src/routes/triviaRoutes.ts
import express from "express";
import { checkAnswer } from "../trivia/checkAnswer";

const router = express.Router();

router.post("/trivia/check-answer", (req, res) => {
  const { questionId, selectedOptionIndex } = req.body;

  const result = checkAnswer(questionId, selectedOptionIndex);
  if (!result) {
    return res.status(400).json({ error: "Invalid questionId" });
  }

  return res.json(result);
});

export default router;

3. Show “right/wrong + explanation” instantly on the client

On the frontend, you already know the questionId and which option they clicked:

// client/src/components/TriviaQuestionCard.tsx
import { useState } from "react";
import axios from "axios";

interface TriviaQuestionProps {
  id: string;
  question: string;
  options: string[];
}

export default function TriviaQuestionCard({
  id,
  question,
  options,
}: TriviaQuestionProps) {
  const [selectedIndex, setSelectedIndex] = useState<number | null>(null);
  const [isCorrect, setIsCorrect] = useState<boolean | null>(null);
  const [correctIndex, setCorrectIndex] = useState<number | null>(null);
  const [explanation, setExplanation] = useState<string | null>(null);
  const [reference, setReference] = useState<string | null>(null);

  const handleSelect = async (index: number) => {
    setSelectedIndex(index);

    const res = await axios.post("/api/trivia/check-answer", {
      questionId: id,
      selectedOptionIndex: index,
    });

    const data = res.data;
    setIsCorrect(data.isCorrect);
    setCorrectIndex(data.correctOptionIndex);
    setExplanation(data.explanation);
    setReference(data.reference);
  };

  return (
    <div className="p-4 rounded-2xl bg-slate-900/70 text-slate-50 space-y-3">
      <div className="text-sm uppercase tracking-wide text-slate-400">
        Bible Trivia
      </div>
      <div className="font-semibold text-lg">{question}</div>

      <div className="space-y-2">
        {options.map((opt, idx) => {
          const isUserChoice = selectedIndex === idx;
          const isRight = correctIndex === idx;

          // Style feedback
          let extraClasses = "";
          if (isCorrect !== null && isUserChoice) {
            extraClasses = isCorrect ? "border-green-500" : "border-red-500";
          }
          if (isCorrect !== null && isRight) {
            extraClasses = "border-green-500";
          }

          return (
            <button
              key={idx}
              onClick={() => handleSelect(idx)}
              className={`w-full text-left px-3 py-2 rounded-xl border bg-slate-800/80 text-sm ${extraClasses}`}
            >
              {opt}
            </button>
          );
        })}
      </div>

      {isCorrect !== null && (
        <div className="mt-2 text-sm">
          <div className={isCorrect ? "text-green-400" : "text-red-400"}>
            {isCorrect ? "Correct! ✅" : "Not quite. ❌"}
          </div>
          {reference && (
            <div className="mt-1 text-slate-300">
              <strong>{reference}</strong>
            </div>
          )}
          {explanation && (
            <div className="mt-1 text-slate-300">{explanation}</div>
          )}
        </div>
      )}
    </div>
  );
}


This gives:

Instant “Correct!” or “Not quite.”

Book and verse shown clearly.

Short explanation reinforcing the right answer.

4. Safety net: validate the trivia bank itself

You can add a tiny script to run whenever you change the questions to catch mistakes like wrong indices:

// tools/validateTrivia.ts
import { TRIVIA_QUESTIONS } from "../server/src/trivia/triviaQuestions";

let hasError = false;

for (const q of TRIVIA_QUESTIONS) {
  if (
    q.correctOptionIndex < 0 ||
    q.correctOptionIndex >= q.options.length
  ) {
    console.error(
      `Question ${q.id} has invalid correctOptionIndex: ${q.correctOptionIndex}`
    );
    hasError = true;
  }
}

if (!hasError) {
  console.log("All trivia questions look valid ✅");
  process.exit(0);
} else {
  process.exit(1);
}


Then in your package.json:

{
  "scripts": {
    "validate:trivia": "ts-node tools/validateTrivia.ts"
  }
}


Run npm run validate:trivia whenever you add/edit questions, so bad data never makes it into production.

5. If you still want AI involvement

If you’re using OpenAI to generate new questions, that’s fine—but:

Generate them offline or in an admin-only tool.

Manually review them.

Save them into your TRIVIA_QUESTIONS file (or database) with a fixed correctOptionIndex.

Never ask the model, “Is the user’s answer correct?” at runtime.
