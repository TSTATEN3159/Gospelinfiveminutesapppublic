### How to use this

You can tell Replit / your dev:

1. **Create (or open) the file:**

```text
client/src/features/discipleship/discipleshipPlans.ts
```

2. Paste this entire code in.
3. Wherever the app needs the plans (e.g. `DiscipleshipScreen`, `DiscipleshipPlanScreen`), import:

```ts
import { DISCIPLESHIP_PLANS } from "@/features/discipleship/discipleshipPlans";
```

4. I can now do the **same TypeScript conversion** for Plans 2–15 so they are all ready to plug in exactly like this one—no extra thinking required from your side, just paste and go.
