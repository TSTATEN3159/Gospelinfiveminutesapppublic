📱 How to Debug in TestFlight
Step 1: Install from TestFlight
Rebuild your iOS app in Appflow and install from TestFlight

Step 2: Connect Device to Xcode Console
1. Connect iPhone to Mac via cable
2. Open Xcode
3. Window → Devices and Simulators
4. Select your iPhone
5. Click "Open Console" button

Step 3: Filter Logs
In the console search box, enter one of these filters:

[Contacts] - See all contact import logs
[Friends] - See all friends fetch logs
[API] - See all backend API logs
Step 4: Test Features
Try Import Contacts
Try Find Friends
Watch the console for real-time logs
Step 5: Share Results

Permission status

API responses
Any errors
🛠️ What to Look For
Common Issues & Their Logs:
1. Permission Denied:

[Contacts] Permission raw: {"contacts":"denied"}
[Contacts] Permission not granted — showing settings prompt

Fix: User needs to enable Contacts in Settings

2. Missing userId:

[Contacts] Missing appUserId!

Fix: User needs to complete registration first

3. iOS 18 Limited Access:

[Contacts] Permission raw: {"contacts":"limited"}
[Contacts] Permission allowed: true
[Contacts] Raw contacts length: 25

Note: Limited access is OK - app will work with subset

4. Backend Error:

[API] POST /api/contacts/:userId/import error { ms: 123, error: 'Database connection failed' }

Fix: Backend issue needs investigation
