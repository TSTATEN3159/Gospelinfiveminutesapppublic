1️⃣ Replace the Focus Verse header block with this

  </p>

  {/* This is the verse line that MUST wrap */}
  <p

  </p>

Key parts:

whitespace-normal → allows wrapping

break-words → long words (or long references) will break instead of pushing out of the box

text-balance → lets the browser balance lines more nicely (where supported)

2️⃣ If this block lives in a flex container, make sure it can shrink & wrap

If the card root is something like:

<div className="flex items-center ...">


then make sure the text container has min-w-0 so wrapping is allowed:

<div className="flex flex-col bg-slate-950 rounded-3xl overflow-hidden shadow-xl">
  <div className="min-w-0">
    {/* paste the Focus Verse block from above here */}
  </div>
  {/* rest of card (image, buttons, etc.) */}
</div>


min-w-0 is crucial in flex layouts—without it, the browser often refuses to shrink the text box, so the text just runs right out of the rounded card.

In your previous code, make sure you delete any of these on the verse <p>:

truncate

whitespace-nowrap

whitespace-pre

overflow-x-auto

Those all fight against wrapping.
