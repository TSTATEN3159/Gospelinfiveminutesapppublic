I’ll assume your front-end is React + Vite (same repo you’re building with Appflow).

1. Install the ticker library in Replit

Open your project in Replit.

Open the Shell at the bottom.

From the project root (where package.json lives), run:

npm install react-ticker


Replit will update package.json and install the library in node_modules.

If your front-end code lives under client/ and you normally run commands from there, you can instead do:

cd client
npm install react-ticker


(Use the same location where you normally do npm run dev.)

2. Add a high-definition “Bible study” image

You can either:

Use a remote stock image URL (simplest), or

Download a stock image into your assets folder (more robust for production).

For now we’ll use a remote Pexels/Unsplash-style URL:

const STUDY_IMAGE_URL =
  "https://images.pexels.com/photos/2080960/pexels-photo-2080960.jpeg?auto=compress&cs=tinysrgb&w=1200";


(You can swap this for any royalty-free HD Bible study / walking / prayer image you like.)

If you want it local later, just download the image into client/src/assets/ and change to:

import StudyImage from "@/assets/bible-study-01.jpg";


and use src={StudyImage} instead of the URL.

3. Create the Scripture Ticker component

In your client code, create a new file, for example:

client/src/components/ScriptureTickerPanel.tsx

Paste this entire code:

What this gives you

Static, “hero-style” verse: big, readable, front and center.

Ticker at the bottom: scrolls through all 25 verses continuously.

HD photo on the right: someone studying/reading/walking with Scripture — very “Daily Gospel in motion”.

You can drop this panel anywhere (home screen, devotional screen, etc.).

4. Use the widget in your app (Home page, for example)

Find the component that renders your home screen — something like:

client/src/pages/HomePage.tsx

or wherever you show the daily card.

At the top of that file, add:

import ScriptureTickerPanel from "@/components/ScriptureTickerPanel";


Then in the JSX, place it where you want the widget to appear. For example:

export default function HomePage() {
  return (
    <div className="px-4 pt-4 pb-20 space-y-4">
      {/* Existing header / daily verse */}
      {/* <HomeHeaderScriptureFocus /> */}

      {/* New ticker widget */}
      <ScriptureTickerPanel />

      {/* Rest of your home content */}
    </div>
  );
}


You can:

Put it right under your existing Daily Verse card to make the screen feel rich and “alive.”

Or put it above to act as a “Scripture banner.”

5. Run and test in Replit

In Replit Shell, run:

npm run dev


(or whatever command you normally use to start the Vite dev server).

Open the web preview:

You should see the new panel:

Static verse on the left.

Ticker line slowly scrolling different verses.

Image on the right.

If it looks too fast/slow, adjust this line:

<Ticker speed={5} mode="smooth">


Lower number = slower scroll (e.g. 3), higher number = faster (e.g. 8).

6. Make some verses static instead of all scrolling

Right now:

One verse is static (featuredVerse).

All 25 verses feed the ticker.

If you want some verses to stay static only and never scroll, you could:

Split the list:

const FEATURED_VERSES = [ /* 3–5 favorite ones */ ];
const TICKER_VERSES = VERSES; // or a filtered copy


Use FEATURED_VERSES for choosing featuredVerse, and TICKER_VERSES inside the ticker.

That way, you can curate what stays “anchored” in front of the user vs. what rotates.
